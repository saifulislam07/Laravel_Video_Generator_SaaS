# টেস্টিং গাইড — Video Generator SaaS

এই ডকুমেন্ট ধরে ধরে অ্যাপের প্রতিটা ফিচার ম্যানুয়ালি টেস্ট করার নির্দেশনা।
প্রতিটা সেকশন = একটা ফিচার। "প্রত্যাশিত ফলাফল" দেখে মিলিয়ে নিন।

---

## 0. প্রস্তুতি (একবার)

### 0.1 সার্ভিস চালু

Laragon-এ **MySQL** চালু আছে কিনা দেখুন। তারপর প্রজেক্ট ফোল্ডারে:

```bash
# ডাটাবেজ + সিড (একবার)
php artisan migrate:fresh --seed

# অ্যাসেট বিল্ড (একবার, অথবা CSS বদলালে আবার)
npm run build

# অ্যাডমিন প্যানেলের static অ্যাসেট (একবার)
php artisan adminlte:install --only=assets --force

# স্টোরেজ লিংক (একবার)
php artisan storage:link
```

### 0.2 চালু রাখতে হবে (আলাদা টার্মিনালে)

| টার্মিনাল  | কমান্ড                     | কী জন্য                                            |
| ---------- | -------------------------- | -------------------------------------------------- |
| 1          | `php artisan serve`        | ওয়েব সার্ভার → http://127.0.0.1:8000              |
| 2          | `php artisan queue:work`   | **রেন্ডার, ইমেইল, পাবলিশ — সব ব্যাকগ্রাউন্ড জব**   |
| 3 (ঐচ্ছিক) | `php artisan reverb:start` | রিয়েল-টাইম স্ট্যাটাস আপডেট (পোর্ট 9090)           |
| 4 (ঐচ্ছিক) | `npm run dev`              | CSS/JS লাইভ রিলোড (তাহলে `npm run build` লাগবে না) |

> ⚠️ **টার্মিনাল 2 (`queue:work`) না চালালে** রেন্ডার "queued"-এই আটকে থাকবে, ইমেইল যাবে না।
> `npm run dev` চালালে থামানোর পর `public/hot` ফাইল থেকে যায় → পেজ স্টাইলহীন দেখাবে। ঠিক করতে: `public/hot` মুছুন অথবা `npm run build`।

### 0.4 Shotstack API key (আসল ভিডিও রেন্ডারের জন্য)

1. https://dashboard.shotstack.io/ এ ফ্রি অ্যাকাউন্ট খুলুন
2. **Stage** environment-এর API key কপি করুন
3. `.env` ফাইলে বসান:
    ```
    SHOTSTACK_API_KEY=এখানে-key
    SHOTSTACK_ENV=stage
    ```
4. `php artisan config:clear` চালান

> key ছাড়াও পুরো অ্যাপ টেস্ট করা যায় — শুধু "Render video" বাটনে পরিষ্কার এরর দেখাবে।
